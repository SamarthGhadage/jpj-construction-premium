# JPJ Construction Premium Homepage

A deploy-ready, static redesign for JPJ Construction. It uses semantic HTML, CSS custom properties, and vanilla JavaScript so it can be shared or deployed to GitHub Pages without a build step.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static web server.

## Deploy

Upload the contents of this folder to a GitHub repository and enable GitHub Pages from the repository's main branch and root folder.

## Notes

- Responsive breakpoints are defined for mobile, tablet, and large desktop layouts.
- External Unsplash images are used as visual placeholders and require network access.
- The contact buttons use the supplied JPJ Construction email, phone, and WhatsApp details.
